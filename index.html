Valuation note

Estimated value = year-end quantity × latest recorded per-item unit value available at year-end. Receipts and distributions are summarized by their recorded dates. This estimate does not determine fair market value or establish a deductible charitable contribution. Consult a qualified tax professional and retain source documentation for audit purposes.

CSV EXPORT

Jotform & other exports

Upload a CSV export from Jotform or another spreadsheet. Review and validate every row before import.

Jotform live API sync is not enabled in this standalone demo. API keys must stay on a secure backend.

Expected CSV columns

Headers are matched case-insensitively. Required: date, type (received/distributed), item, and quantity. Optional: category, size, unit_value, source, notes. Quantity must be a positive whole number; unit value must be zero or greater. Distribution quantities cannot exceed available stock.
